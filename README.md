# 🇯🇵 Japanese Holiday Coach — 30-Day Learning Plan

A fully self-contained Progressive Web App (PWA) to take you from beginner to holiday-ready Japanese in 30 days, with under 30 minutes of study per day. Works offline once installed.

---

## 📁 Repository structure

```
japanese_coach.html        ← The entire app (single HTML file)
index.html                 ← Redirect page for GitHub Pages root URL
manifest.json              ← PWA manifest (makes the app installable)
sw.js                      ← Service worker (enables offline use)
icon.svg                   ← App icon
audio_manifest.json        ← Maps 2,469 Japanese phrases to local MP3 paths
generate_audio.py          ← One-time script to download all audio files
audio/                     ← MP3 files (generated by GitHub Actions)
.github/workflows/
  generate_audio.yml       ← GitHub Actions workflow to generate audio
README.md
```

---

## 🚀 Deploying to GitHub Pages

1. Upload all files to a GitHub repository
2. Go to **Settings → Pages → Source → main branch / root**
3. Your app is live at:
   ```
   https://YOUR-USERNAME.github.io/REPO-NAME/
   ```
   The `index.html` redirect will forward to `japanese_coach.html` automatically.
4. Go to **Actions → Generate Audio Files → Run workflow** to download all audio files
5. Bookmark the URL on your phone

## 📲 Installing as an app (PWA)

The app is a Progressive Web App — it can be installed directly on your phone's home screen and works offline.

**On Android (Chrome):**
- Open the app in Chrome
- Tap the **📲 Install App** button in the app header, or tap ⋮ → *Add to Home Screen*
- The app opens like a native app with no browser chrome

**On iPhone / iPad (Safari):**
- Open the app in Safari
- Tap the Share button (□↑) → *Add to Home Screen* → *Add*

Once installed, the app loads fully offline. Lesson content, progress, and cached audio all work without internet.

## 🔊 Setting up audio

The app plays audio from three sources in priority order:

| Priority | Source | Works offline? | Requires setup? |
|----------|--------|---------------|-----------------|
| 1st | Local MP3 files in `audio/` | ✅ Yes | Run GitHub Action once |
| 2nd | Google Translate TTS | ❌ No | None |
| 3rd | Device SpeechSynthesis | ❌ No | None |

### Generating audio files (do this once via GitHub Actions)

1. In your repository, go to **Actions → Generate Audio Files**
2. Click **Run workflow → Run workflow**
3. Wait ~15 minutes — the workflow downloads all 2,469 MP3 files and commits them

The audio covers every lesson phrase, all kana syllables, and all 2,136 Joyo kanji.

### Saving audio for offline use

After installing the PWA and generating audio files:
- Tap **📥 Save audio offline** in the app header
- A progress bar shows while ~10 MB of audio is cached to your device
- Keep the screen on — takes 2–3 minutes on a good connection
- After this, every 🔊 button works with no internet

## 💾 Progress across sessions and devices

Progress saves automatically in `localStorage` every time you complete a task.

**To transfer progress to another device:**
- Tap **💾 Export** in the app header → saves a `.json` file
- On the new device, tap **📂 Import** → select the file

The export includes **all settings** — completed tasks, current day, colour theme, speed preference, romaji toggle state, dictionary favourites, and streak.

## ✨ App features

### Learning tabs
| Tab | Description |
|-----|-------------|
| Week 1–4 | Daily lessons — vocab, speaking, listening, grammar, review |
| かな Kana | Full hiragana and katakana chart with audio and progress tracking |
| 漢字 Kanji | All 2,136 Joyo kanji by grade with readings and audio |
| 一覧 Phrases | All lesson phrases grouped by day, searchable |
| 辞書 Dictionary | Situation-based phrase dictionary with usage notes and favourites |

### Lesson task types
- **Vocabulary** — type each word 3× to master it; accepts hiragana or kanji forms
- **Speaking** — press 🎤, say the phrase, app checks pronunciation
- **Listening** — press ▶ to hear each phrase 3× at your chosen speed
- **Grammar** — reading and explanation
- **Review** — weekly checkpoint

### Header controls
| Button | Function |
|--------|----------|
| 🔥 Streak | Days studied in a row |
| あ Romaji ON/OFF | Show or hide pronunciation guides across the whole app |
| 🐢/🔊/🐇 Speed | Audio playback speed: Slow (0.5×) / Normal (0.75×) / Fast (1.0×) |
| 💾 Export | Save progress and settings to a JSON file |
| 📂 Import | Restore from a previously exported file |
| 🎨 Personalise | Change colour scheme (6 presets + custom colour pickers) |
| 📲 Install App | Install as a PWA (appears when Chrome detects the app is installable) |
| 📥 Save audio offline | Pre-cache all audio files for offline playback |

### Progress tracking
- Overall progress bar in the header (tasks complete / total)
- Day completion celebration when all tasks on a day are finished
- Coverage indicators on Kana, Kanji, and Phrases tabs:
  - **Bold grey outline** = character/phrase seen in 1–2 completed lessons
  - **Green outline** = seen in 3+ completed lessons

## 🎤 Microphone / speech recognition

Speech recognition requires an internet connection (Chrome delegates to Google's servers). When offline, a text input appears automatically instead.

### Text fallback
If the mic is unavailable or offline, a text input appears below the mic button. It accepts:
- **Romaji** — type `konnichiwa` and it converts to こんにちは automatically
- **Hiragana / katakana** — type directly in Japanese
- **Kanji** — also accepted

### Microphone not working on Xiaomi / HyperOS?

Chrome's site settings (🔒 lock icon) are not the only permission layer. Check:

1. **Phone Settings → Apps → Chrome → Permissions → Microphone → Allow**  
   This is Android's own app-level permission, separate from Chrome's site settings.

2. **Play Store → search "Speech Services by Google" → Install / Update**  
   Chrome on Android delegates speech recognition to this app. On Xiaomi/HyperOS it is often missing or outdated.

After changing either setting, fully close Chrome (swipe from recents) and reopen.

## 🔧 Updating the app

To update `japanese_coach.html`:
1. Go to your repository on GitHub
2. Click **Add file → Upload files**
3. Drag the new `japanese_coach.html` onto the upload area — GitHub replaces it automatically
4. Click **Commit changes**

GitHub Pages updates within ~1 minute. The service worker will pick up the new version on the next page load.

If you also update `audio_manifest.json` (e.g. after adding new content), re-run the **Generate Audio Files** workflow to download any new MP3 files.
